# 빅데이터 Insight: 지역별 유입인구

지역마다 다른 지역에서 들어온 이동이 평소보다 많은지 적은지를 보여 주는 MCP 서버와 안내 사이트입니다.
축제·연휴·날씨 같은 그 주의 일도 함께 알려 줍니다.

> 개인이 개발한 참고용 서비스로, 정부 공식 통계가 아닙니다.
> 판정·추정·예측은 이 서비스의 계산이며, 자료를 제공한 기관의 입장이 아닙니다.

- 사이트: https://nowcast-mcp.azurewebsites.net/
- MCP 연결 주소: https://nowcast-mcp.azurewebsites.net/mcp (인증 없음)
- 공식 MCP 레지스트리: io.github.KevinCapri/nowcast-mcp

## 할 수 있는 것
- 시군구·주 단위로 다른 지역에서 온 유입이 평소와 얼마나 다른지 판정
- 한 주나 기간을 골라 전국에서 평소와 가장 크게 달랐던 지역 찾기, 한 지역이 언제 평소와 크게 달랐는지 찾기
- 한 지역·한 주를 지난 해 같은 주와 평소 대비끼리 비교(설·추석은 그 해 명절 주끼리)
- 축제 기간의 유입 변화, 다가올 축제 주의 참고 예측
- 생활인구가 아직 공표되지 않은 달의 참고 추정
- 시군구 주민등록인구·등록외국인(공표 값) 보기
- 날짜별 방문자(한국관광공사 값과 평소 같은 요일 대비). 관광공사 값이 아직 없는 최근 약 한 달은 이동 자료로 미리 추정한 범위
- 외부에서 들어오는 이동이 많은 시군구 순위(10곳씩, 주민 1명당 순으로도, 인구감소지역(관심지역 포함, 관심지역은 *)·인구활력+지역(+)만 골라 보기)
- 결과에 함께 붙는 날씨·공휴일
- 지역·기간의 일정(축제·대형 행사·공연·프로야구·벚꽃·단풍)과 그 주 유입, 해마다 전국 벚꽃·단풍 관측일

## AI에 연결하기
- Claude: 설정 → 커넥터 → 사용자 지정 커넥터 추가 → 위 MCP 연결 주소 입력
- ChatGPT: 설정 → 통합 → 플러그인 → 사용자 지정 MCP 서버 추가 → 위 MCP 연결 주소 입력
- 자세한 방법은 사이트의 'AI 연결 방법' 탭을 참고하세요.

## 자료 출처
- 국가데이터처 KOBIGS 나우캐스트, 통신 모바일 인구이동량(SK텔레콤 통신자료 기반 추정)
- 국가데이터처 KOSIS: 생활인구, 주민등록인구, 등록외국인, 타지역 통근
- 한국관광공사 한국관광 데이터랩: 지역별 방문자 수
- 기상청 종관기상관측(ASOS) 일자료
- 한국천문연구원 특일 정보
- 문화체육관광부 지역축제 개최 계획(일부 대표 축제는 기사·공식 안내로 날짜 확인)
- 소상공인시장진흥공단 전국전통시장표준데이터
- 한국문화관광연구원 관광자원통계(주요 유료관광지 월별 방문객)
- 대형 시설 개점·폐점: 회사 발표·보도, 행정안전부 생활_대규모점포
- 인구감소지역·인구감소관심지역: 행정안전부 재지정·고시(2026-10-07)
- 통근 인원: 국가데이터처 인구총조사(2020), 새로 생긴 구는 한국교통연구원 국가교통DB 수도권 목적OD(2024)로 나눔
